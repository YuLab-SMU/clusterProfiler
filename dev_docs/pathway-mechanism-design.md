# 通路层面的机制解说：设计

状态：设计稿（待审核）。日期 2026-10-30。分支 `pathway-mechanism`，基线 `4.21.4.024`。
前序：`mechanism-evaluation-proposal.md`、`mechanism-evaluation-spec.md`（TF 中心那一版的实测结论）。

---

## 1. 为什么要转向

TF 中心的那一版做完了，结论是**它选不出正确的调控者**。这不是实现问题，是方案问题。三条实测：

| 证据 | 数字 |
|---|---|
| 准入集过宽 | 中位准入 **182 / 被检验 868 ≈ 21%**；`tfunion` 下 658 / 1192 ≈ 55% |
| 判别力弱 | 真值进准入集的 lift = **1.75**（`tf`）；`tfunion` 在 S1 上 **0.92 = 瞎猜** |
| 加库是权衡，不是改进 | 准入集 182→658，命中率 37.5%→50%，但 S1 的 lift 1.75→**0.92**；同一份库在 S2 又只有它能到 **1.46** |

也就是说：**"能找到"是因为门开得大，不是因为认得出。**

加库不是简单的坏事：S1 上它把信噪比稀释到瞎猜的水位，S2 上它是唯一能用的东西。
**它买到覆盖，代价是判别力**——这个权衡本身就该是设计要回答的问题，不能说成"加库反噬"。

问题出在哪：C3:TFT / 并集库是用来回答"这个 TF 的靶基因是哪些"的，而我们拿它回答
"这批基因由谁调控"。**这两个问题不等价。** 一个 TF 的靶集命中你的基因列表，只说明
它的结合偏好与你的列表重叠，不说明它在这次实验里是驱动者。

**另外，排名口径本身错了**：MRR / top1 问"真值是不是第一"，等于把机制解说当成单基因还原。
敲掉一个转录因子扰动的是一个程序，第二、第三若也是真调控者，按"没排第一"记失败就是错的。

## 2. 一个必须先纠正的历史判断

`biotrigger` 在 R3 被删掉了。依据是：加上它之后 **TF 排名逐位不变**（15/54、MRR 0.083）。

**那把尺子后来被证明是错的。** 用"能不能让 TF 排得更高"去评判一个**程序层面相似性**的
工具，等于用体重秤量身高。`biotrigger` 回答的是"什么扰动看起来像我这个程序"，
不是"哪个 TF 该排第一"。

**在新框架里它可能是核心那一层。** 这不是"设计变了所以要复活它"——是承认当初的判据选错了。

---

## 3. 新的主张

> 富集分析给出的是**有哪些通路在动**；机制解说要回答的是**什么扰动会产生这样的程序**，
> 并且给出**可被独立扰动数据检验**的因果陈述。

关键差别：

| | TF 中心（旧） | 通路 + 扰动（新） |
|---|---|---|
| 骨架 | 用户自己的富集结果 + TF 库 | 用户自己的富集结果（GO / KEGG） |
| 机制层 | "哪个 TF 调控这批基因" | "什么扰动产生这个程序" |
| 证据类型 | 数据库收录的靶集（B/C 级） | **主证据是实测扰动相似性（A 级）**；成员方向一致性与 PPI 仍是 B |
| 答案形态 | 一个名字 | 一组可检验的因果陈述 |
| 判据 | 真值排第几 | 复现、反证、特异性 |
| 覆盖问题 | 严重（C3:TFT 只有部分 TF） | 轻（用户本来就有通路） |

**"机制"不再是一个名字，是一组能被数据推翻的话。**

---

## 4. 数据源与证据分级

沿用 A/B/C 纪律，但重新对应到通路层面：

| 级 | 含义 | 在这个框架里是什么 |
|---|---|---|
| **A** | 实测扰动 | GPSAdb 的扰动数据集：某基因被敲低/过表达后，这条通路的成员基因确实整体移动 |
| **B** | 记录下来的机制 | 通路数据库的层级关系、PPI 里的直接互作、KEGG/Reactome 的上下游注解 |
| **C** | 关联 | 共表达、通路成员重叠、文献共现 |

**A 级可以用，因为它是实测的。** 旧框架里 perturbagen 被判"不算独立证据"是因为它与真值同源；
新框架的真值不是 GPSAdb 的敲除基因，所以那条循环不再成立——**但必须重新检查异源性**（见 §8）。

可用接口（已确认存在）：

```
gpsadb_biotrigger(genes, effect, limit)      # 基因列表 -> 哪些扰动产生相似特征
gpsadb_test_gene_set(dataset_id, genes)      # 基因集 -> 在某数据集里响应与否
gpsadb_gsea(dataset_id, library, ...)        # 数据集内部的通路层面结果
```

## 5. 设计决策

| # | 决策 | 理由 |
|---|---|---|
| **P1** | **骨架是用户自己的富集结果**，不重新跑富集 | 用户的通路列表就是他关心的问题集；重跑等于替他改问题。已有 `pathway=` 入口可复用 |
| **P2** | **TF 不再当骨架，降为可选上下文** | 它回答的是另一个问题。保留它是为了"如果要看上游是谁"，不是默认路径 |
| **P3** | 机制层的主证据是**扰动相似性**，集合命中降为辅助 | 集合命中**不是无效**——TF 靶集在你的差异基因里富集，说明它与这次实验有关。但从"有关"到"驱动"缺一步，而这一步恰好是判别力所在：门开 21% 时 lift 只有 1.75，它认不出谁在驱动。扰动是实测的因果干预，能补上这一步 |
| **P4** | 每条通路的结论必须带**方向**与**成员支持比例** | 少数基因驱动的高分不能算作整条通路的支持（沿用旧 spec §7.2 的判断） |
| **P5** | 机制陈述必须**可被推翻**：明确指出"若 X 驱动它，则敲掉 X 应当abolish 它" | 不可falsify 的陈述不是机制陈述。这是与旧框架最大的分野 |
| **P6** | 评价终点是**复现 / 反证 / 特异性 / 跨源一致**，不是"认出正确答案" | 见 §6 |
| **P7** | 任何证据必须与真值**异源**（细胞系/组织/研究层面） | 旧框架已经踩过：MCF7 真值 + MCF7 证据，看起来是独立确认，其实是同一个实验 |
| **P8** | 不承诺"找回通路库里没有的通路" | 与旧框架同样的现实限制，承认它，不绕 |

### 5.1 输出形态（结构化的理由见 §10-1）

每条富集通路一行，**可解析**，因为 §6 的检验要读它：

```
pathway             direction  members  support  driver      evidence  verdict
response to hypoxia up         33/40    0.83     HIF1A       A         mechanism
                                       -> 若 HIF1A 驱动此程序，敲低它应当使这 33 个成员回落
response to hypoxia up         ...      ...      EPAS1       A         candidate
                                       -> 同上；与 HIF1A 的特征可区分度 0.31（低）
glycolysis          down       8/22     0.36     -           -         unsupported
                                       -> 成员方向不一致，不构成为一条通路整体移动的证据
```

四列是关键：

- `support` = 方向一致且过阈值的成员占比。**少数基因驱动的高分不能算整条通路的支持**（P4）。
- `driver` 可以有多个。**不做"选出一个赢家"**——这正是旧框架被圈死的地方。
- `verdict` 取值沿用 `supported` / `candidate` / `unsupported`，语义映射到路基层面。
- 每行附一句**可被推翻的陈述**，这是 P5 的落点。

## 6. 评价框架（这一节是设计的核心）

### 6.0 先决条件：评价需要的数据，现在还没有

§6 的四个终点都要求 **≥2 个独立数据集**，而且至少一个数据集有**已知扰动**。
现有三个例子都不满足：

| 例子 | 是否满足 |
|---|---|
| 缺氧 GSE319526 | 只有一份；论文里没有配套的扰动数据 |
| airway | 有 GPSAdb 的 GR 敲低，但**同为气道细胞系**（与真值同源，见 P7） |
| MCF-7 | 有 GPSAdb 的 ESR1 敲低，但**同为 MCF7**（已确认 GSE153250 vs GSE246363） |

**所以在做第 3 期之前，必须先选定一套评价数据**：同一生物学问题、≥2 个独立研究、
其中至少一个带已知扰动。这是开工前要定的事，不是做的时候再说。

**第 0 期不受此限**（它只问 biotrigger 有没有地基），可以先做。

### 6.0b 缺氧试点的评价数据已选定（2026-10-30 核查）

按 P7（证据须与真值异源）核查 GPSAdb 的 HIF 家族扰动数据。结论是**可以满足**：

| 真值 | 数据 | 细胞系 |
|---|---|---|
| 缺氧程序 | GSE319526 | **Panc1**（胰腺癌） |

| 可用扰动臂 | GPSAdb | 细胞系 | 是否异源 |
|---|---|---|---|
| `HIF1A` 敲低 | D22946 | HeLa | ✓ |
| `HIF1A` 敲低 | D23437 / D23438 | UM-RC-2 | ✓ |
| `EPAS1` 敲低 | **D21860** | **HUVEC-C**（内皮） | ✓ 且跨谱系 |
| `EPAS1` 敲低 | D20682 / D20683 | MCF7 | ✓ |
| `VHL` 敲低 | D23147 | HK-2 | ✓ |
| `ARNT` 敲低 | D21106 | AsPC-1 | ✓ |

**没有任何一个 HIF 家族数据集来自 Panc1**，所以缺氧试点天然满足异源要求。
其中 `EPAS1` + `HUVEC-C` 最有力：内皮细胞是缺氧生理的天然场所，与胰腺癌细胞
既不同细胞系也不同谱系。

**这条对任何机制层都成立**，不依赖 biotrigger 的结论——所以它不会因第 0 期失败而作废。

### 6.0c 下一次第 0 期重测的判据必须先定刻度

上一版判据的缺陷是没固定 `limit`（见 §7.2）。任何重测**必须在跑之前**写死下面四项，
缺一项就不算判据：

| 项 | 必须固定为 |
|---|---|
| `limit` | 一个确定的数，写进文档（例如 50） |
| 通过位置 | 驱动因子的名次上限（例如 ≤ 10） |
| 与相邻的**间隙** | 例如与第 k+1 名的差 ≥ 某值——这是上一版真正缺的东西，**只看名次不看间隙，等于允许"埋在一堆等价候选里"过关** |
| 失败后做什么 | 停止并记录，不改判据 |

**间隙这一项是本轮新增的**：biotrigger 的失败不是"排得靠后"，是"排第 18 和第 200 没有区别"。
判据若不测量区分度，就会把"埋掉"误判成"找到"。

旧框架问"你找对了吗"，新框架问"你说的话经得起检验吗"。四个可测终点：

### 6.1 复现（replication）
同一条通路的机制陈述，在两个**独立数据集**上是否都成立。
- 判定：数据 A 提出的扰动 X，在数据 B 上 `test_gene_set` 仍然显著。
- 不需要外部真值，只需要两个数据集。

### 6.2 反证（refutation）
声称"X 驱动这条通路"后，敲掉 X 的那份数据里这条通路是否**真的**动了。
- 判定：`test_gene_set(数据集X, 通路成员)` 的 padj 与方向。
- **这是最硬的一条**：它直接检验因果陈述，而不是相似度。

**⚠ 必须用另一份数据集检验。** 若 X 是从数据集 D 的相似性里提出的，再用 D 去验证 X，
那是同义反复——D 当然会显示 X。检验必须落在 **D′ ≠ D** 上（同 P7）。
这一条不写清，"反证"这个词就是假的，而它恰恰是整节里最硬的一条。

### 6.3 特异性（specificity）
提出的扰动 X 是只解释这条通路，还是对所有通路都"像"。
- 判定：把 X 的特征与**随机通路**、与**其他富集通路**分别比对，看区分度。
- 若 X 对什么都像，那它没有解释力——**这与旧框架 lift≈1 是同一种失败**。

### 6.4 跨源一致（cross-source agreement）
扰动证据、通路数据库注解、PPI 拓扑三者是否指向同一个方向。
- 只作辅助：不一致时降低置信，不作为否决。

**不报"总体准确率"。** 四个终点分别报，与旧 spec 的多终点纪律一致。

## 7. 分期

| 期 | 内容 | 判据 |
|---|---|---|
| **0** | **先导验证**：缺氧数据的 `response to hypoxia`，成员基因跑 `biotrigger` | 见下方三档判据 |
| **1** | `evidence()` 通路模式：每条通路附成员方向一致性 + 扰动相似性，按 A/B/C 分级 | 三个旧例子能跑通，输出可读 |
| **2** | 机制陈述生成：每条通路给出"若 X 驱动则……"的可检验陈述 | 陈述能被 6.2 的检验实际推翻或支持 |
| **3** | 评价：在 ≥3 个数据集上按 §6 四个终点报告 | 至少一个终点有量化结果 |

**第 0 期是生死判据。** 在写一行产品代码之前先做它。

### 7.1 第 0 期结果：不通过（2026-10-30）

按预登记判据执行，两个例子：

**先记一次更正。** 初版记录写的是"缺氧、airway 都没有命中 HIF/GR"，那是**只看了 top-20** 得出的。
把 `limit` 放到 200 之后，缺氧的答案其实在列表里：

| 因子 | 在 200 个候选中的位置 |
|---|---|
| `VHL` | **18** |
| `HIF1A` | **28** |
| `EPAS1` | **186** |
| `ARNT` / `EP300` / `CREBBP` | 未出现 |

ES 从第 1 名的 0.975 到第 200 名的 0.871，**200 个候选的极差只有 0.104**。
所以准确的说法不是"没找到"，是**"找到了但埋在一堆几乎等价的候选里"**——
`VHL` 第 18、`HIF1A` 第 28，而它们上下都是 ES 只差 0.01–0.02 的无关因子。

airway 不同：`GR` / `NR3C1` 在 200 个候选里**完全没有出现**。

| 例子 | 通路 | 成员 | 重叠中位 | 驱动因子的位置 | top1 |
|---|---|---|---|---|---|
| 缺氧 | `response to hypoxia` | 40 | 30 | `VHL` 18、`HIF1A` 28、`EPAS1` 186（共 200） | BMAL1 |
| airway | `extracellular matrix organization` | 24 | 20 | **未出现**（200 个里） | TP53 |
| airway | `muscle adaptation` | 12 | 11 | 未出现 | RYBP |
| airway | `muscle system process` | 28 | 26 | 未出现 | ZFP91 |

### 7.2 判据本身的缺陷（比结果更值得记）

原判据写的是"返回项里出现 `HIF1A`/`HIF2A`/`EPAS1` 中任一个 → 通过"，**但没有固定 `limit`**。

- `limit = 20`：不出现 → 不通过
- `limit = 200`：HIF1A 出现在第 28 → **字面上通过**

**一个结论会随一个未固定的参数翻转的判据，不是判据。** 这是本设计里最严重的一处缺陷，
因为它不在被测对象上，而在**量具**上。§10 记的那十处都是"话比数据硬"，这一处是
"尺子本身没定刻度"。

**补救：按实质判定，并把理由写清楚。**

> 判据的本意是"biotrigger 能不能**指向**驱动者"。`VHL` 排第 18、`HIF1A` 排第 28，
> 而 200 个候选的 ES 极差只有 0.104——**排第 18 和第 200 在实际使用上没有区别**，
> 因为没有一个可用阈值能把它们分开。airway 那一例更干脆：驱动者根本不在列表里。

**结论：不通过，方向停止。** 这次的理由是"排序无法区分"，不是"没找到"——
前者更难反驳，因为 airway 那一例已经从另一个方向证明了同一个结论。

**失败是信息，不是事故。** 三点诊断：

1. **重叠充分，所以不是"测不出来"。** 中位 20/24、26/28 的成员都进了数据集，
   biotrigger 看见了这条通路，仍然返回 TP53 / RYBP / ZFP91 这些与该实验无关的因子。
2. **ES 压缩在 0.90–0.98，排序没有区分度。** 缺氧那例第 1 名 0.975、第 20 名 0.941，
   差 3%。**这与 TF 准入集过宽、lift≈1 是同一种失效模式**：给出一个很宽、很平的列表，
   顶端并不比底端更有意义。
3. **唯一一次命中也说明了问题**：缺氧的 `VHL` 排第 18（VHL 是降解 HIF-1α 的 E3 连接酶，
   机制上正确）。但它在第 18 位、而前 17 位全是无关因子——**即使答案在列表里，
   排序也把它埋掉了**，等于不可用。

**这意味着 `biotrigger` 作为机制层不成立**，与它当初被删的理由不同：那次是说它不改善 TF 排名
（判据错了），这次是它在**自己该回答的问题**上也给不出可用的答案。两次结论一致，但证据基础不同。

### 7.3 第 0 期重测（机制层 = `test_gene_set`）：判据先定

`biotrigger` 失败后，下一个候选机制层是 `gpsadb_test_gene_set(dataset_id, genes)`——
它不排序"谁最像"，而是直接问**这条通路的成员在某份扰动数据里是否整体移动**。
问的是 yes/no，不是相似度，所以不会天然产出又宽又平的列表。

**判据在跑之前写死（四项全部固定）：**

| 项 | 固定值 | 理由 |
|---|---|---|
| 通路 | 缺氧 `response to hypoxia`，40 个成员 | 与上次同一条，可比 |
| 阳性集 | 5 个 HIF 轴扰动数据集：`D22946`(HIF1A/HeLa)、`D23437`(HIF1A/UM-RC-2)、`D20682`(EPAS1/MCF7)、`D23147`(VHL/HK-2)、`D21106`(ARNT/AsPC-1) | 都是异源（非 Panc1），且覆盖 HIF 通路的不同节点 |
| 零分布 | 每份数据集再测 **20 个同 size 的随机基因集**（背景基因里抽） | 匹配 size 的经验 p，不需要生物学真值 |
| **通过** | 真实通路的 `padj` 在 5 份数据集里 **≥3 份排进 21 个里的前 2**，且至少一份的 leading edge 含 HIF 靶基因（`CA9`/`VEGFA`/`SLC2A1`/`NDRG1`/`ANGPTL4` 任一） | 同时要求**统计显著**与**生物学可读**，缺一不算 |
| **失败** | 停止并记录，不改判据 | — |

**这次量的是区分度，不是名次。** 真实通路要和 20 个同 size 随机集比——这正是
biotrigger 缺的那一环（它只和自己在 200 个候选内部比，而那 200 个彼此只差 0.10）。

### 7.4 第 0 期重测结果：**通过**（2026-10-30）

按 §7.3 预登记的判据执行，结果：

| 数据集 | 细胞系 | 真实通路 padj | 21 个里排名 | leading edge 中的 HIF 靶基因 |
|---|---|---|---|---|
| `D22946` HIF1A | HeLa | 0.0000 | **1** | **10**（CA9, VEGFA, SLC2A1, NDRG1, ANGPTL4…） |
| `D23437` HIF1A | UM-RC-2 | 0.0000 | **1** | 6 |
| `D20682` EPAS1 | MCF7 | 0.0062 | **1** | 6 |
| `D23147` VHL | HK-2 | 0.3464 | 6 | 3 |
| `D21106` ARNT | AsPC-1 | 0.0607 | **2** | 4 |

- 排进前 2：**4/5**（判据需 ≥3）✓
- 含 HIF 靶基因：**5/5**（判据需 ≥1）✓
- **判定：通过。**

**这次和 biotrigger 的差别是本质的。** biotrigger 在 200 个候选里把答案埋到第 18，
而 `test_gene_set` 把真实通路排到 20 个同 size 随机集里的**第 1**，且 leading edge 是
一整套教科书级 HIF 靶基因（CA9 / VEGFA / SLC2A1 / NDRG1 / ANGPTL4）。**排序有一道清晰的间隙。**

方向上也对：HIF1A / EPAS1 敲低让通路**下降**（es 为负），符合"敲掉 HIF 就关掉缺氧程序"。
`VHL` 那一例 es 为负且不显著——与"VHL 丢失应稳定 HIF、通路上升"的预期不符，
**这是一个未解释的点，记下来，不掩盖**（HK-2 是肾近端小管细胞，VHL 生物学在此背景下可能不同）。

#### 一次险些误判

自动判据第一次跑出来是**不通过**，原因是 `leading_edge_genes` 是**列表列**，
`as.character()` 把它去解析成了 `list("VEGFA", ...)` 字符串，导致关键词一个都匹配不上。

改成 `[[1]]` 取元素后，同一判据给出 5/5。**判据没有被改动，改的是测量。**

教训要记：**自动判据也会因为测量 bug 给出错误结论，而与手工观察矛盾时，必须去查测量，
不能直接把自动结果当成事实。** 这次如果没去核对"D22946 明明有 CA9"这个矛盾，
会得出"方向不成立"的反向错误结论。

**但方向本身没有因此被判死。** 第 0 期只测了 biotrigger 这一个机制层。
`test_gene_set`（拿通路成员去检验指定数据集的响应）问的是另一个问题，可能更有希望——
不过**换机制层是重新设计，不是抢救**。新方案必须重新过一遍第 0 期，不能直接往上走。

判定必须事先写死，否则事后总能找到说法：

| 结果 | 判定 |
|---|---|
| 返回项里出现 `HIF1A` / `HIF2A` / `EPAS1` 中任一个 | **通过**，进入第 1 期 |
| 返回项里没有上述任一，但有其他缺氧/低氧相关的已知因子 | **部分通过**，记录命中位置；再跑一个第二例子（airway 的 GR）确认不是偶然 |
| 返回为空，或全是无关项 | **不通过，方向停止**。不要改判据去迁就结果 |

后者的意义：**先导验证失败也是有效结论**，能省掉后面全部工作。

### 7.5 第 1 期实现记录（2026-10-30）

`R/pathway_evidence.R`：`pathway_evidence(x, drivers, signed, alpha, min_support, max_pathways)`
加 `print.pathway_evidence()`。7 条测试，`R CMD check` 0/0/0。

**入口是 `enrichResult`，不是 `evidence()`。** 这是实现时明确的架构点：
P1 说骨架是用户自己的富集结果，那么 `pathway_evidence(enrichResult)` 就是自然的入口，
再塞进 `evidence()`（它吃的是基因列表）反而是往回走。目标里"实现 `evidence()` 的通路模式"
应按此修订——**通路模式是并列入口，不是 `evidence()` 的一个开关**。

**审核发现并修掉的两个缺陷：**

1. `support` 恒真。方向由成员多数推导时，一致性必然 ≥ 50%，`min_support = 0.5` 永远满足，
   每条有方向的通路都白得一个 B。修法：只有方向来自外部（`pathway_direction` / `NES`）时，
   成员一致性才算独立证据。
2. A 级不看扰动方向。任何显著结果都记支持，包括把通路推向同一方向的那种——那是压制不是驱动。
   修法：方向冲突记 `direction-conflict`，降到 B。

**一次虚警（记录以示区分）：** 我曾怀疑陈述里的成员数（33）与 `n_members`（19）不一致。
核查后**不是缺陷**——10 行里 8 行带成员数，与 `n_members` 全部相符；33 vs 19 是打印时
列分组错位，19 属于 `cellular response to hypoxia`，被对到了 `response to hypoxia` 的陈述上。
**报出来的怀疑要查清，查清是虚警也要说。**

**缺氧试点**（`adjudicate-interpret/scripts/21_pathway_evidence.R`）：
6 条通路达 A，ARNT/A-498 与 HIF1A/HeLa 的 `es` 均为负（敲掉驱动者后程序回落），
判 `activator`；候选驱动者来自四个细胞系，**没有一个是 Panc1**（真值数据），异源要求满足。

## 8. 风险

- **循环性没有消失，只是转移了。** 真值若是"这条通路由 X 驱动"而证据也来自 GPSAdb，仍可能同源。
  缓解：P7 要求异源；每份证据记录 `dataset_id` 与细胞系，报告里明示。
- **相似 ≠ 因果。** `biotrigger` 给的是"像"，不是"导致"。措辞必须严格：说"与该扰动特征一致"，
  不说"由该扰动导致"，除非有 6.2 的反证检验支撑。
- **通路成员重叠导致假复现。** 两条通路共享大量成员时，一个扰动会同时"解释"两者。
  缓解：特异性检验（6.3）必须跑，不能只看复现。
- **`biotrigger` 的 500 行上限**（旧 spec 已踩过）。记录覆盖比例，覆盖低时不给强结论。
- **书的叙事要跟着调。** 原来那一章叫"从通路走向机制"，弧线把 TF 当机制层的出口。
  新框架是"停在通路上、加深外部证据"，两者兼容但**不是同一个故事**。
  这章已经写好的部分需要重新对照，不能只改代码不改文字。
- **已归档例子的结论要重新标注。** MCF-7 的 `activator` 是在同源证据上得出的（P7 那个问题），
  新框架下它的证据等级应降为"未验证"，而不是继续引用。

## 9. 与旧框架的关系

**保留**：`evidence()` 的输入/输出契约、A/B/C 分级、`absent`/`untested`/`failed` 三分、
`adjudicate()` 的多来源互证纪律、`interpret()` 的裁决约束叙述、E1 的叙述错误注入套件、
E3 的覆盖可见性。

**降级**：`$regulators` 从"答案"变成"可选上下文"。**具体含义**：它仍然会被填充、
仍然可以打印，但**不再参与通路层面的 verdict**。否则会出现"通路说 unsupported、TF 说
supported"的两种结论并列，读者不知道该信哪个——旧框架的问题不是结论少，是结论多。
若要看上游，那是另一个入口（`upstream="tf"`），不是一个混合的默认输出。

**新增**：通路模式、扰动相似性通道、机制陈述生成、§6 的评价。

**不改**：`mechanism_sets()` 的集合库、`enrichGO`/`enrichKEGG` 的行为。
